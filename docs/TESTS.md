# TESTS — Claude 시안 자체 테스트

환경: Chrome(헤드리스) 390×844 터치 에뮬레이션, 1280×860 다크모드. **실제 iPhone 검증은 아직 안 함.**

| # | 시나리오 | 결과 | 비고 |
|---|---|---|---|
| 1 | 앱 열고 오늘 일정·할 일 확인 | 통과 | 샘플 데이터 표시 확인 |
| 2 | "내일 오후 3시 치과" | 통과 | 일정, 내일 15:00 |
| 3 | "우유 사기" | 통과 | 할 일 |
| 4 | "오늘은 바람이 차가웠지만 마음은 따뜻했다." | 통과 | 일기(한 줄) |
| 5 | "금요일 7시 반 저녁 약속" | 통과 | 이번 금요일 19:30 |
| 6 | 반복 근무 입력 | 통과 | 빠른 입력 한 줄(+ 버튼, 입력, Enter) 또는 일정 시트에서 매주+요일 |
| 7 | 할 일 완료 / 내일로 | 부분 확인 | 체크·버튼 확인. 스와이프는 실기기 확인 필요 |
| 8 | 어제 기록 보기·수정 | 통과 | 날짜 화살표, 달력 |
| 9 | 한 줄 일기 + 기분 | 통과 | 새로고침 후 유지 확인 |
| 10 | 삭제 후 실행 취소 | 통과 | 일정 삭제 → 실행 취소로 복원 확인 |
| 11 | 다크모드 | 통과 | 시스템 설정 연동 |
| 12 | iPhone·PC 동일 작업 | PC만 확인 | iPhone 홈 화면 설치 후 확인 필요 |

빠른 입력 해석기는 13개 문장으로 단위 확인 (README 표 참고).

## 추가 기능
| 기능 | 결과 | 비고 |
|---|---|---|
| 주간 목표 만들기·체크·달성 알림 | 통과 | 빠른 입력 "주 2회 스트레칭" 포함 |
| 일정↔목표 연결, 지난 일정 "했나요?" | 통과 | |
| #write / #add 바로가기 | 통과 | 크롬. iPhone 단축어는 미확인 |
| 기상·취침 기록, 자정 넘긴 취침 → 전날 처리, 수면 시간 계산 | 통과 | 시계 고정 테스트(23:40 / 07:20 / 00:50 / 07:05) |
